##############################################################################
# Dawn and Dusk ideology spectrum
#
# Eight groups, left to right. The group is what the map and the politics
# screen show ("Social Democrat"); the type under it is the specific flavour
# shown as the main label ("Developmental State", "Modern Putinism").
#
# KEYS: four of the eight groups reuse vanilla HOI4's internal keys, so the
# hundreds of vanilla scripts the mod still loads (laws, factions, peace
# conferences, autonomy, AI...) keep resolving instead of crashing the game.
# Players never see these keys; the names come from localisation/english/
# replace/dnd_ideologies_replace_l_english.yml.
#     communism  = Vanguard Communist     democratic = Liberal
#     neutrality = Despotic               fascism    = Ultranationalist
# The other four (socialist, social_democrat, conservative,
# authoritarian_democrat) are new.
#
# Each of those four groups also lists vanilla's flavours (nazism,
# despotism...) as story-only types for the same reason. Nothing gives them
# out. Types marked can_be_randomly_selected = no are only ever set by script
# at an inflection point, never given to random leaders. Extremes (Year Zero,
# Chrome Capitalism, Holy War...) are all story-only.
##############################################################################
